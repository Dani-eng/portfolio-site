# portfolio-site
A responsive personal portfolio presenting my background in computational fluid dynamics (CFD), fluid–structure interaction (FSI), multiphysics simulation, and aerospace-related research.

Features:
- Professional introduction and technical skills
- Selected research projects and peer-reviewed publications
- Education, research, and industry experience
- Conference presentations and certifications
- Résumé downloads for U.S. and Canadian audiences
- Email and LinkedIn contact links
- Light/dark theme toggle with the selected theme saved in browser storage
- Accessible navigation, including a skip-to-content link

In progress:
- Adding video and images for published research

The website can be found at: https://dani-eng.github.io/portfolio-site/
